# MANGA FORGE Full Stack

## اجرا روی کامپیوتر
1. Node.js را نصب کن.
2. داخل این پوشه CMD/PowerShell باز کن.
3. `npm install`
4. `npm start`
5. مرورگر را روی `http://localhost:3000` باز کن.

امکانات: ثبت‌نام/ورود واقعی، JWT، bcrypt، SQLite، کتابخانه و علاقه‌مندی، کاتالوگ، فصل و خواننده، پنل مدیریت، API و آپلود.

برای مدیر شدن، مقدار role حساب در جدول users را به `admin` تغییر بده.
برای انتشار آثار دارای حق نشر باید مجوز صاحب اثر را داشته باشی.
